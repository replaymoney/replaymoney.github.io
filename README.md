# Replay Money — methods & code

Public methods pages and simulation code for the Replay Money YouTube channel.

- `ep01/` — Episode 1: *If the AI bubble pops, what happens to your 401(k)?*
  - `ep01/index.html` — the methods page
  - `ep01/code/` — the model (`ai401k_model.py`), `run_all.py` (reproduces every number in ~8 s), results and parameter notes

Run it: `pip install numpy` then `python3 ep01/code/run_all.py`.

Educational simulations, not financial advice.
